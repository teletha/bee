bee.task

Manages the JDK used by Bee. The JDKs are downloaded from Adoptium (Temurin) and installed under the Bee home directory, so the JDK can be switched without touching the environment path. Early Access builds are supported for versions which have not been released yet.

AVAILABLEString

The endpoint which lists the available releases.

select()void

Select the JDK used by Bee. All the versions available on Adoptium are listed, and the selected one is downloaded, installed and configured as the JDK used by Bee.

intversion

A JDK version.
psychopath.Directory
