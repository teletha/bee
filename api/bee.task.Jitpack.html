Jitpack

  • kiss.Extensible
  • TaskConfig

Manages the JitPack builds of the project. The latest version is checked and, when its build failed, the failed build state is deleted and a new build is triggered.

The deletion requires the JitPack API token, which is read from the JITPACK_TOKEN environment variable or the jitpack.token entry of the Bee user configuration. Without the token the build is only retriggered.

POLL_INTERVALlong

The interval (ms) between the build status polls.

TIMEOUTlong

The maximum time (ms) to wait for the build.

build()void

Check the latest JitPack build and rebuild it when it failed.
