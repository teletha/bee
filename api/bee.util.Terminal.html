Terminal

  • AutoCloseable

A low level terminal controller which switches the console between the canonical (line) mode and the raw mode. In the raw mode the arrow keys are delivered to the program immediately, so the user can navigate a list without pushing the enter key.

This class uses the FFM API to call the platform native function directly.

raw()Terminal

Terminal

A terminal controller.

Enter the raw mode. If the terminal can not be switched to the raw mode, the returned instance is disabled and #isEnabled() returns false.

isEnabled()boolean

boolean

A result.

Check whether the raw mode is active or not.

read()int

int

A read byte, or -1 when the input is closed.

Read one byte from the console. This method blocks until a byte is available.

width()int

int

A terminal width, or -1 when it can not be detected.

Resolve the current terminal width in columns. The width is queried from the native console because Java does not expose it. An accurate width is important for the user interface which erases a dynamic message by moving the cursor up by the number of the lines the wrapped message occupies.

restore()void

Restore the original console mode.
