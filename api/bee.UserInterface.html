SPINNER_FRAMESString

The frames of the spinner.

SPINNER_MARKERString

The marker which a spinner message may contain to place the animated frame at an arbitrary position. Every occurrence is replaced by the current frame, so a message can animate more than one position. It uses a control character which does not appear in ordinary text.

SPINNER_INTERVALlong

The interval (ms) between the spinner frames.

CUIUserInterface

The for command line user interface.

This field must be declared after all constants which the command line user interface reads in its static initializer.

confirm(Stringquestion)boolean

Stringquestion

Your question message.
boolean true for yes.

Ask user about your question and return his/her answer. The answer is one of yes or no, and the enter key selects the safe default, which is no. An invalid answer is asked again with a short prompt.

select(Stringquestion, ListStringnames)int

Stringquestion

Your question message.
ListStringnames

A list of displayable item names.
int

A 1-based index of the selected item.

Show a list of selectable items and ask user to select one of them.

This default implementation displays all items with their numbers and requires the user to input a number. A user interface which can control the terminal can override this method to select an item interactively.

read()String

String

A user input, or null when the input is closed.

Read a line from the user input sink.

The reader is cached because a new reader discards the bytes which the previous reader has already buffered.
