bee.util

GithubAPI

A minimal client for the GitHub REST API.

Authentication is performed with the OAuth 2.0 Device Flow, so no client secret is required and the user only needs a browser to authorize this tool. The issued access token is cached in the user's home directory and reused on the following invocations. Set the GH_TOKEN or GITHUB_TOKEN environment variable to bypass the interactive authorization (which is convenient in CI).
