GithubAPI.Settings

The repository settings which can be applied by #configure(String, Settings). Add new settings as fields and handle them in #configure(String, Settings).

canApprovePullRequestReviewsboolean

Whether GitHub Actions can submit approving pull request reviews.

allowMergeCommitboolean

Whether merge commits are allowed on pull requests.

deleteBranchOnMergeboolean

Whether head branches are deleted automatically after a pull request is merged.

hasDiscussionsboolean

Whether GitHub Discussions is enabled.
